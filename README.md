## 🌟 Overview

**MarketFlow** is a sleek, mobile-first product discovery platform designed to curate and showcase trending products from Shopee. Built with a stunning dark-themed UI and vibrant neon gradients, it delivers an immersive browsing experience with multi-language support (English & Indonesian) and real-time analytics.

---

## 🚀 Key Features

*   🌙 **Immersive Dark Theme**: Premium UI crafted with modern CSS gradients (Orange, Pink, Blue accents).
*   🌐 **Bilingual Experience**: Seamless switching between English and Indonesian (`id`/`en`).
*   📱 **Mobile-First Architecture**: Fully responsive layout optimized for all devices.
*   🔍 **Advanced Discovery**: Instant search, category browsing, and curated featured products.
*   📤 **Social Commerce**: One-click sharing integration for WhatsApp, Telegram, Facebook, and Twitter.
*   📊 **Built-in Analytics**: Track user engagement and product click-through metrics.
*   🔐 **Secure Admin Dashboard**: Complete backend management for products, categories, and site configurations.
*   💰 **Localized Currency**: Clean IDR (Indonesian Rupiah) formatting out of the box.

---

## 🛠️ Tech Stack

*   **Frontend**: HTML5, Modern CSS3, Vanilla JavaScript (Zero framework bloat)
*   **Database**: SQLite3
*   **Backend**: PHP (Optional for dynamic server-side operations)
*   **Storage**: LocalStorage (Static mode) / Server Database (Dynamic mode)
